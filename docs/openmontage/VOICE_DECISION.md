Kokoro replaces Piper `en_US-lessac-medium` for narration. Piper lessac is **NOT cleared** for published/monetized videos (see §4).

## Kokoro training-data provenance (from the official model card)

Kokoro-82M was trained exclusively on permissive/non-copyrighted audio data and IPA phoneme labels. Permissive/non-copyrighted audio includes:
- Public domain audio
- Audio licensed under Apache, MIT, etc.
- Synthetic audio generated by closed TTS models from large providers (no synthetic audio from open TTS models or "custom voice clones")

**Creative Commons Attribution items in the v1.0 dataset:**

## Residual risks

1. **Training-data provenance:** CC BY items (Koniwa, SIWIS) require attribution if the trained model's output is deemed a derivative. The model card does not state whether attribution is discharged by training.
2. **Synthetic data origin:** UNKNOWN — providers not disclosed; cannot verify they were "closed TTS models from large providers" as claimed.
3. **Weights vs. data split:** weights are Apache-2.0 (clear), but the training data carries the caveats above.

These risks do not block the weights-level license (Apache-2.0), but they mean the voice is **not unconditionally cleared** for monetized publication without an owner decision.

## Verification performed (Milestone V)

- `kokoro` 0.2.2 installed via pip (binary wheels; `spacy`/`thinc`/`blis` source build failed on Python 3.14, resolved with `--only-binary=:all:`)
- Kokoro-82M weights `kokoro-v1_0.pth` (~313 MB) downloaded to `/tmp/hf-cache` (within 600 MB cap; gitignored, not committed)
- CPU synthesis of a public-domain paragraph with 3 voices (af_heart, af_bella, am_adam): RTF 1.58–1.75 (slower than real-time on CPU — expected), all synthesized to `/tmp/*.wav` (not committed)
- espeak-ng **not installed** → `WARNING: EspeakFallback not enabled. Out-of-dictionary words will be skipped.` (non-fatal; misaki G2P still works for in-dictionary words)
- QC tool (`tools/qa/qc.py`) on each sample: raw kokoro output is quiet (I=-21.8 to -25.4 LUFS → ebur128 FAILED vs -14±2 target); decode PASS on all
- `finish_audio` (`tools/audio/finish_audio.py`) on af_heart: I=-15.0 LUFS, TP=-4.4 dBFS → PASS
- Native `aac` encoder available; s16 wav → aac MP4 mux works; FINISHED MP4: I=-15.0 LUFS, TP=-4.3 dBFS, ebur128 PASS, full_decode PASS

**Note:** AAC encoders were reported broken in this ffmpeg build in D2 (pcm_f32le→aac and s16→aac-after-limiter produced silence/-70 LUFS). The working path is finish_audio → pcm_s16le wav → native `aac` encoder mux. Use the native `aac` encoder for the final mux, not a direct f32→aac encode.

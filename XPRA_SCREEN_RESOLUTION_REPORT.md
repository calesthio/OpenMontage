# XPRA_SCREEN_RESOLUTION_REPORT.md

**Дата:** 2026-11-01
**Среда:** GitHub Codespaces (`unhallowed-spooky-hobgoblin-qv5p94wpj5r3xw69`)

## Исходное состояние

| Параметр | Значение |
|----------|----------|
| Разрешение Xvfb :99 | 1280x720 |
| Максимальный фреймбуфер Xvfb | 1280x720 |
| Размер окна Chrome | ~1280x720 (развёрнут на весь экран) |

## Попытки исправления

### 1. xrandr --fb 1920x1080

```
xrandr: screen cannot be larger than 1280x720 (desired size 1920x1080)
```

**Результат:** ОШИБКА — Xvfb был запущен с фиксированным размером экрана `-screen 0 1280x720x24`, который жестко ограничивает максимальный фреймбуфер до 1280x720.

### 2. xrandr --output default --mode 1920x1080

```
warning: output default not found; ignoring
```

**Результат:** ОШИБКА — нет поддерживаемых режимов кроме 1280x720.

## Причина

Xvfb был запущен командой:
```
Xvfb :99 -screen 0 1280x720x24 -ac +extension GLX +render -noreset
```

Параметр `-screen 0 1280x720x24` жестко задает размер виртуального экрана. После запуска Xvfb невозможно изменить разрешение через `xrandr --fb`, так как это требует пересоздания X-сервера.

## Причины невозможности исправления без перезапуска

1. **Xvfb не поддерживает динамическое изменение разрешения** после запуска. Размер экрана фиксируется при старте параметром `-screen`.
2. **Нельзя перезапускать Xvfb** — это привело бы к закрытию Chrome и потере текущей сессии Google Flow (если авторизация уже активна).
3. **Нельзя перезапускать Xpra** — это разорвет текущее подключение пользователя.

## Рекомендации

Для исправления разрешения до 1920x1080 необходимо:

1. Остановить Chrome (завершить сессию Google Flow).
2. Остановить Xpra shadow.
3. Остановить Xvfb.
4. Запустить Xvfb с `-screen 0 1920x1080x24`.
5. Запустить xpra shadow :99 с новым разрешением.
6. Запустить Chrome снова с `--window-size=1920x1080`.
7. Пользователю требуется повторная авторизация в Google Flow через Xpra.

## Резервный вариант

**noVNC** остается доступным на порту 6080 (`https://unhallowed-spooky-hobgoblin-qv5p94wpj5r3xw69-6080.app.github.dev`) с разрешением 1280x720. Пользователь может использовать его как временное решение.

## Статус

**Невозможно исправить без перезапуска Xvfb.** Текущее разрешение 1280x720 остается неизменным до перезапуска X-сервера.

# Architecture Pivot V5 — Hybrid Documentary (No Host Character)

## What was (V4)
- SVG stickman host character (rig + GSAP paused timeline), flat/illustrative style.
- Single-topic pilot: "planet with no land".
- Branch `archive/stickman-concept-v4` preserves the full V4 state.

## What becomes (V5)
- No on-screen host character; pure voiceover over visuals (documentary format).
- Hybrid visuals: archival/stock footage (NASA, Archive.org, Wikimedia, Pexels/Pixabay) where real footage exists + photorealistic AI frames (Nano Banana 2.1) where real footage is impossible.
- Channel scope is broader: speculative science documentary (speculative biology/geology, space, deep time, thought experiments, alternate history). The "ocean planet" pilot remains the first release of this line, not the only topic.
- Mandatory visible "AI-generated visualization" slate/branding at the start of videos containing realistic synthetic content.

## Why
- Avoid character-consistency burden; improve realism and documentary credibility.
- Use free licensed footage where possible; reserve AI generation for impossible shots.
- Comply with YouTube synthetic-content disclosure and avoid "fake footage" accusations.

## Archive
- V4 full state: branch `archive/stickman-concept-v4` (pushed).
- Character files are intentionally left in place in this branch for now; not deleted at this step.

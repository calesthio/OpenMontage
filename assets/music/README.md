# Музыкальная подложка для пилота

Этот каталог предназначен для файла музыки из YouTube Audio Library.

## Как добавить музыку (шаг B2)

1. Владелец выбирает трек в YouTube Audio Library и скачивает его.
2. Кладёт файл сюда: `assets/music/<название>.mp3` (или .wav).
3. Агент (сборка + микширование) автоматически:
   - добавляет трек в финальную сборку,
   - микширует с narration-аудио,
   - обновляет `projects/pilot/manifests/youtube_package.json` с кредитами,
   - запускает финальный QC (категория A3).

Файл не коммитится в git (аудио-артефакт, не исходный код).

## Ожидает решения владельца (B2)

# VISUAL_STYLE_GUIDE — Стиль кадров пилота (Klein 4B)

## Общая техника (все кадры K1–K4)
- thick crisp black outer contours — чёткие чёрные контуры по периметру объектов
- controlled interior linework — управляемая внутренняя прорисовка (штриховка, акценты)
- large flat matte color fills — большие равномерные мазки матового цвета, без текстур
- clean two-tone cel shading — чистый двухтоновыйセル-шейдинг (свет + тень, без промежуточных тонов)
- restrained palette — ограниченная палитра (не более 4–5 цветов на кадр)
- no gradients — градиенты запрещены, только плоские закраски

## Палитра пилота (из script.md image recipe)
- night ink — тёмный сине-чёрный фон
- deep sea teal — глубокий морской бирюзовый
- pale bone — бледно-костный (осветлённые поверхности)
- electric teal — электрический бирюзовый (акцентные линии/свет)
- coral accent — коралловый акцент (одна точка цвета на кадр)

## Разрешение и пропорции
- 1280×720 (16:9, кратны 16)
- 4 шага дистиллята (Klein 4B), guidance_scale=1.0 (CFG выключен)
- Негативные промпты не работают — формулировать только позитивно
- До 4 референсных изображений (multi-reference, нативный метод консистентности Klein)

## Промпты
- Только нарративные, подробные промпты (prompt upsampling нет)
- Техника обязательно прописывается явно в каждом промпте
- Стиль: graphic-novel ink illustration, bold, flat, cel-shaded

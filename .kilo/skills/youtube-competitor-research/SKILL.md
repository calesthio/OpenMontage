# YouTube competitor research

Use `youtube_competitor_research` (yt-dlp + youtube-transcript-api) before writing scripts.

Rules:
- Run before script writing; record findings in research_brief.
- Analyze titles, hooks, structure, and claims; never copy scripts.
- Fetch transcripts only for analysis; do not republish.
- Mark unverified claims; use primary sources for facts.
- Zero-cost: yt-dlp and transcript API are free; no paid API.

# Idea Director — Product Intake

## Prerequisites

No prior artifact. Initialize `projects/<project-id>/`.

## Process

1. Ask for one clear product image, the product name, known selling points, and target platform.
2. Verify the image is readable, reasonably sharp, and no larger than 10MB.
3. Describe the process in beginner language: four previews, choose 1–3 styles, three images each, one 8-second video each, three copy variants, and music approval.
4. Write `brief` with `product_image_path`, `product_name`, `known_selling_points`, `target_platform`, and `assumptions`.

Never infer ingredients, materials, certifications, or performance claims.

## Approval

If product facts are missing, ask one open question. Then present 3 choices:

1. Use only the supplied facts (recommended).
2. Add facts the user provides now.
3. Stop so the user can prepare better product information.

Write `awaiting_human` and end the turn. 停止并等待用户审批。

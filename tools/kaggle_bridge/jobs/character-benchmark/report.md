## Персонаж (STICKMAN)

Белая круглая голова, толстый чёрный рисованный контур, два маленьких чёрных овальных глаза, одна слегка приподнятая бровь, простой рот, тонкие чёрные руки/ноги/туловище, тёмно-бирюзовый шарф с крошечным коралловым кончиком, чистый 2D ink/sticker art, плоская заливка, тёплый белый фон.

### 2. Qwen-Image-Edit-2511 — НЕ ПРОТЕСТИРОВАНА

| Причина отказа | Детали |
|----------------|--------|
| Требование bf16 | Карточка модели требует `torch.bfloat16`. На Tesla T4 нет аппаратной поддержки bf16 (только fp16/int8). Модель не может запуститься natively на T4. |
| Размер весов | Полные BF16 веса ≈ 57.7 ГБ (20 млрд параметров) превышают VRAM T4 (14.56 ГБ). |
| Квантованный вариант | Есть 32 квантованных варианта на HF, но не подтверждён вариант, совместимый с одной T4 (fp16 + под bf16-архитектуру). |
| Решение | Не скачивалась, не тестировалась. Отказ зафиксирован до любой попытки загрузки. |

## Вывод и рекомендация

- **Рабочая модель:** `black-forest-labs/FLUX.2-klein-4B` — единственная реально запустившаяся на T4 конфигурация. Генерация проходит без OOM на 512×512, fp16, 4 шага, guidance 1.0, batch=1. Пик VRAM ≈ 8.3 ГБ.
- **Консистентность персонажа через native image conditioning (img2img с исходным изображением)** реализуется без адаптеров. Степень сохранения'identité между кадрами требует визуальной проверки по `contact_sheet.png`.
- **Qwen-Image-Edit-2511 не применима на T4** (bf16-only + 57.7 ГБ весов) — исключена из пилота.
